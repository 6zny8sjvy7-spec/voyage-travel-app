## 重要資料安全
- `localStorage` 是每個瀏覽器／裝置各自保存，不能由 GitHub commit 直接備份使用者手機資料。不得清空、覆寫或擅自刪除。
- 不能保證不同手機之間的原本本機資料自動同步；只有有後端設定且啟用的共享功能可能跨裝置。
