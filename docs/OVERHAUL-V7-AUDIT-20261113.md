## 後續確認的決策（必須一起保留）

- 不買 API／交通資料／地圖／付費託管；不要求信用卡；免費額度不足就明示限制。
- 選國家自動顯示繁中／英文／當地語言（KR/TH/JP/VN），只顯示已驗證的站名翻譯，車號不亂翻。
- A→B 必須可以選多條公車方案，逐條顯示車號、方向、搭幾站、下車站、中間站、步行／轉乘；幾站依該班次 stop_sequence 計算。
- 到站分鐘只有經核對路線方向與站牌的真即時資料才顯示；表定只顯示「表定 HH:mm」。
- 「不導外網」適用交通查詢，不以 Google/NAVER/官方網作為失敗替代；資料來源的授權歸屬不等於導外查路線。
- 絕不加入 GPS 自動追車、假班次與假倒數。
- 原版會跳動的國家地標和獨立天氣卡、明顯日夜視覺及既有日期／活動紀錄不可倒退。
- 單一安排活動入口；航班從交通分類進；無限按需增天數（原應用上限 366 天）。
- 單日／週下方地圖；沒有單獨地圖頁；Google/NAVER 僅原本的手動地點導航功能，不能代替內建交通助手。
- 原正式首頁檔不動；同一測試 URL 發佈前必須跑 Chrome + WebKit 回歸，輸入／重開／切換旅行不得刪資料。

## 發布與審查準則

1. 每次編修限原 V2 檔案／新增隔離模組，不得整包舊 V1 覆蓋。
2. 綁定 GitHub Actions 的 Playwright 桌面 Chromium 和模擬 iPhone WebKit；新加 packing、week swipe、日期與匯入後可編輯四項驗收。
3. 真實現場 API 覆蓋與真正共編不能靠 mock 代替；無法取得認證資料時明確列為尚未達標。
4. GitHub Pages 部署成功不代表手機實機 Safari 完整驗收。僅在明確標示狀態下交付，不能說「全部完成」而隱藏限制。
