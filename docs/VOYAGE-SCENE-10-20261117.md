1. **移動飛機**：從核准 941×1672 原圖中提取飛機本人、透明去背形成 PNG sprite（朝右上），取代自行重畫的醜 SVG。原有飛行動畫時序與方向保留。
2. **左／右卡片底部插畫**：取自**同一張核准原圖**，將機場/塔台/地面飛機與韓屋/植栽做成兩片只有插畫的 WebP 透明素材。並非將整張包含文字的設計截圖當作網站 UI。
3. **標題、日期、航班資訊、三個待辦**：均為真正 HTML + CSS 元素。checkbox 可實際勾選，保留預覽用的獨立儲存鍵。文字與卡片比例由原始設計調整，保留深藍框線、粉色與奶油色、圓角及白底票券。
4. **響應式取捨**：桌面右欄兩張卡上下排列；窄手機讓同樣兩張卡保持橫向鄰接、可左右滑動且有第二張露出一角，以維持原稿字級可讀性。曾試過在 390px 強行兩欄會讓中文文字小到約 9px，因此沒有使用該失敗版。此為手機適配取捨，若用戶要求嚴格同屏雙卡應先討論可讀性。
5. 其他 Scene08 的首頁結構、列車、天氣、日期、分頁、行程、交通、翻譯、費用均**不做功能改寫**，不觸碰原 V7 資料與檔案。
