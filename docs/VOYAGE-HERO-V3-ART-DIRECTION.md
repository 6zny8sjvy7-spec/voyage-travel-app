# VOYAGE｜第一關首頁美術重做 — 首爾 Hero V3（2026-11-16）

> **狀態：第一幅原創插畫與實際手機尺寸版面樣稿已完成，使用者尚未核准。** 此輪並未修改 VOYAGE V7 App、測試網址或正式頁面。不要用此稿取代已認可的內頁，也不要把圖片當成已完成天氣動畫。

## 為什麼重做
- 使用者於 V1 / V2 iPhone Safari 截圖和錄影否決首頁插畫與動畫：Emoji 機車、拉麵、椰子、浮動貼紙及粗糙飛機動畫全部不合格。
- V2 交通卡與全站極簡分框等部分獲使用者接受，**必須保留**。
- 先做**單一首爾日間場景**以驗收美術品質，不再先畫四個低品質示意城市。其他三國、雨雪夜動畫需等美術方向核准後才製作與整合。

## 這輪實際成果
1. 一幅原創首爾春日城市插畫：**透過專用影像生成工具產生**，不是 Emoji 拼貼。內容可作 Hero 日間靜態場景；不能稱它本身已會動。
2. 重新設計手機首屏結構：城市插畫作為獨立上半部；旅程名稱／日期／倒數放在下半部實色卡，避免文字壓在插畫上；下方保留「下一個行程／出發提醒」卡與六個底部分頁的視覺定位。非舊版 V2 的全屏疊字方式。
3. 實際 390px 行動版 Chromium 截圖已產生，影像確實載入；Safari 真機尚待使用者驗收。HTML 是**離線單頁視覺審查**，非可操作的真實 VOYAGE App。
4. 目前的倒數日數是示意，未接用戶旅程資料；天氣也未接 API。列車/飛機都在插畫內，不以 Emoji 移動冒充真動畫。
