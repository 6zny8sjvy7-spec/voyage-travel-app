## 自動化測試

1. **Node**：`node --test tests/voyage.test.cjs`：CSV 引號、ICS、時區、衝突、費用分攤、日期、所有模組啟動、實際新增行程和費用。
2. **Browser**：`npm run test:e2e`：桌面 Chromium + **模擬 iPhone 13 的 WebKit**，對五頁籤、搭乘助手、記帳重開、分人打包、匯入不覆蓋、附近百科同意新增、雲端未設定提示、日記／購物清單、跨時區行程及出發倒數進行操作。
3. Github Actions：`.github/workflows/ci.yml` 在此分支及 PR 上執行。CI 若失敗，應修正並重新執行；**沒有綠燈不得宣稱已通過**。WebKit 模擬測試並不等於實體 iPhone Safari 測試。
4. 外部服務：Supabase 真實多人同步、官方車輛位置與獨立 AI 搜尋仍屬外部依賴，不得當作完成。
