## 不可降級或隱瞞的總則
- 使用者不接受任何付費 API、付費託管、綁信用卡才能啟用的功能；免費試用不算永久免費。
- 交通查詢結果**直接在 VOYAGE 同頁**；沒有站序或有條件不可用時顯示無資料，不用外部路線頁替代，不猜正確站數、不猜即時倒數。
- 有可信真實資料才可顯示進站 X 分；只有時刻表要寫「表定 HH:MM」，不能偽裝即時。
- 韓／泰／日／越依國家自動使用已核實的繁中、英文、官方當地語言。沒權威對照時保留原名，不能編造。
- 多路線公車：每張方案顯示實際線號、搭乘站數、上車站、下車站、方向、轉乘及有資料的步行與行車時間。若下車站不同，分別顯示供使用者選擇。
- 航班日期與時區只用來判斷持續時間／時間線；用戶機票當地起降日期時間原樣保存，無任意調整。
- 不恢復 AI 景點推薦，不加入已取消的 GPS 列車追蹤，不重建 V1、不清空任何旅行資料。

## 驗收與發布門檻
1. 瀏覽器 Chromium + iPhone WebKit 功能與視覺完整回歸必須全數通過；不把修正測試文案算 APP 的新功能。
2. 公開原網址更新後另測原網址的 UI、費用、貼上匯入、跨旅行保存，確認 GitHub Pages deploy success。
3. iPhone 實體 Safari 尚未人工驗收時標示「模擬 iPhone WebKit」，不能當實體測試。
4. 真實交通資料驗收必須有四國不同路線／公車樣本及來源，未驗證的內容繼續列為阻擋項；不可拿 mock 通過數字代表線上有資料。
5. 多人共編只有在兩個獨立帳號真正同步、權限及衝突驗證成功後才標記完成。
6. 不能默默變更正式網站首頁 index.html 或兩套 localStorage 資料鍵；發布只更新既有 V2 固定測試目錄。

## 已知第三方免費資料使用風險
Transitous 是志願者提供的 best-effort 輕量非商業服務，有明確歸屬和使用規則（https://transitous.org/api/）。它不保證韓泰日越所有地鐵與公車的完整覆蓋和即時資料，故不能作為全功能完成保證。專案正式對外持續使用前，需確認是否符合其開源授權要求（當前 repo 可能尚未有 LICENSE；不得未經專案擁有人授權擅自選 license），以及公開來源連結歸屬規定。
