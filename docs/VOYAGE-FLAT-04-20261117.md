## 這輪已真正實作的內容
1. 首爾平塗城市背景（依使用者核准方向，無字美術板）、可獨立移動的**原創 SVG 列車與飛機**（不是 emoji），背景保留首爾塔／漢江／城市景物。
2. 天氣四鍵**真正可操作**：晴天柔光、雨天 Canvas 多速度斜雨與水面漣漪、雪天落雪、夜景天色與星光。全部是**手動視覺動畫展示**，未接即時天氣 API，也未完成四個國家的獨立場景；不得謊稱實際天氣。
3. 實際 HTML 出發日期與回程日期設定、真正依旅行目的地時區計算出發倒數；日期可修改、示例旅行名稱可儲存。
4. 獨立隔離 localStorage key `voyage-approved-flat04-demo-only-v1`，**未讀寫 V7 真正旅行資料**（`voyage-v2-review-20261112`、`voyage-v02`）。
5. 首頁行程／提醒卡與三個待辦 checkbox 真正可操作；六個分頁可切換。
6. 單日／週總覽切換、日期點擊、當地代表性建築物 SVG 小標記跟日期跳動、真正展開全部交通中間站。
7. 四國切換時交通站序/繁中＋當地站名/方向會切換；**其他三國首頁主圖顯示「美術尚未製作」**，絕不將首爾誤當泰國或日本。翻譯及拍照頁為介面設計，不偽造第三方翻譯或 OCR 結果。
8. 保留先前使用者認可的簡潔小分框／時間軸／交通資訊卡／六個主分頁方向。
