# VOYAGE｜第一階段全站版面設計規格 V1（2026-11-16，待使用者視覺核准）

> **設計文件 ≠ 程式已完成。** 本輪只建立 UI 架構及視覺原型，不動既有 V7 APP、資料及部署。永遠先讀 [唯一接續入口 Issue #2](https://github.com/6zny8sjvy7-spec/voyage-travel-app/issues/2)。

## 一、設計目標
- 「精緻、帶一點可愛的智慧旅行手帳」，不是企業後台／Excel，也不是用粉藍紫換皮或照抄參考 APP。
- 給 iPhone 真實旅行時容易按、容易看；筆電需獨立排版，不能沿用壓縮的 288px 多欄時間格。
- 目前 **視覺規格未核准**；只能在獨立 design 分支作概念展示。所有示範文字、車站、天氣、價格若非即時連線，必須標示「示意」，不可當成實際路線/查詢。

## 二、全站共同設計語言
- 亮色：霧白基底、天空藍主要操作、少量奶油黃/柔和淡紫/橘暖色的旅行重點，不使用大面積粉紅綠色；深色為深藍＋溫和對比。至少保留易讀字級與 WCAG 合理對比。
- 卡片：柔和圓角 16–24px、輕微陰影、清楚區塊節奏；不大量粗邊框與排列過密圖表；卡片功能要比裝飾重要。
- 圖示：🚇 地鐵、🚌 公車、🚶 步行、✈️ 飛機、☕ 餐飲、🛏️ 住宿、📍 景點、🧳 行李、🗣 翻譯等小圖示統一分類且保留語意；避免「公車顯示地鐵」。
- 互動：日期點按縮放／選中回饋、日期上方飛機圖案移動與跳動、首頁地標輕微動態、底部導覽按壓回饋**禁止退版**；`prefers-reduced-motion` 需有減動態。
- 導覽草案：**首頁／行程／交通／翻譯／費用／更多** 6 分頁；需測最窄 iPhone 的點擊面積、底部 safe-area 和標籤是否擠壓；單次點擊有可見反應。
- 所有頁面與行程共用旅行/城市/日期設定。不顯示無資料的假結果、假同步、假即時。

## 三、各頁版面配置（設計稿而非功能完成宣告）

### 1. 首頁／旅行出發心情
- 上方目的地、旅行切換、城市及當地日期；主視覺 Hero 提供目的地代表建築與真實晴雨雪／日夜聯動動畫，未取得資料時顯示「未更新」且不捏造天氣。
- 出發倒數、旅行日期；今日下一站／今日交通提醒／已儲存航班住宿摘要。
- 快速工具可卡片化；較少使用的入口可移入「更多」，**功能本身不可刪**。
- 日/夜閱讀模式放設定，城市動畫依目的地天氣/時間自動顯示。

### 2. 行程／單日為主、週總覽為輔
- 預設「單日」，日期卡可左右滑，週總覽也可橫向滑動，點週卡開單日；新增旅行天數不限於三日。
- 每個單日事件左側起訖時間，以時間軌道表達實際長短；右側卡片絕不裁字，短事件保留最低可閱讀高度，時間長短仍可從軌道辨別；時間未核定時顯示「待確認」，不自填假數值。
- 交通在事件之間用小圖示和精簡轉乘摘要呈現，依地鐵／公車／步行／航班正確分類。點活動可在頁內地圖定位，進入編輯不破壞單點定位；無可核座標不偽造地圖位置。
- 桌面採 8:4 或類似雙欄：左時間軸、右側當日地圖/提醒/住宿；週總覽每欄保有可讀寬度並橫滑。手機一欄，底部安全區完整。

### 3. 交通／清楚判斷搭對方向
- A 起點、B 終點、日期/當地時間／公共運輸類型，提供可確認候選站；成果為卡片式路線。
- 每段展示線名／**往哪個終點站方向**／出站與上車／真正站數／下車／轉乘；「繁體中文＋當地官方名」與可信站碼；摘要之外可展開全部中間站。
- 來源需提供國家→城市→營運商→線路→方向→班次停靠的完整覆蓋度矩陣。**本輪不做即時進站倒數 UI**，因使用者先要求拿掉；只有真實有效班次資料可顯示表定。
- 假資料不得顯示為真查詢，不能把外部地圖當做 APP 內真實交通查詢的替代品。

### 4. 翻譯／一鍵即用
- 優先獨立主分頁：文字翻譯（雙向，繁中+目的地語言）／拍照翻譯（相機、相簿／截圖，OCR 原文可編輯，後才送第三方翻譯）／旅行句型（四國各情境）。
- 朗讀、複製、放大給當地人看；四國韓/泰/日/越隨國家自動預設、仍允許手動改；越南文常用句型待補。
- **現有文字、回譯、朗讀已存在；拍照 OCR 尚未開發**。免費翻譯供應商、OCR 語言包、裝置語音、Safari 權限皆需實測，不能只做按鈕。

### 5. 費用／旅行錢包
- 旅行總預算/剩餘/已花/多幣別摘要 + 分類卡片 + 支出明細 + 旅伴分攤；風格更像旅途錢包，不像公司報帳。
- 既有記帳/匯率換算/資料來源及時間/原始金額與歷史紀錄**禁止刪改**；呈現與邏輯分開。

### 6. 更多／旅行工具箱
- 美食、購物願望、行李、機票住宿、旅行紀錄、匯入/備份、翻譯快捷入口、好友協作（尚未真正同步時明示未啟用）、旅行設定。
- 保留舊功能，不要只在首頁刪掉一個入口後內頁也消失。AI 景點推薦已依使用者舊決定移除，不擅自加回。
- 「附近找看看」僅預留可行性評估，2km 包含 0～2km；四國真實 POI 資料與免費負載限制未測過，不得在真 APP 顯示假結果。

## 四、資料與安全硬性護欄
- 不動 main/index.html；原 V2 網址不變；原 localStorage `voyage-v2-review-20261112`、正式版 `voyage-v02` 不變；不能清除紀錄、悄悄改資料格式、整包覆蓋 V1。
- 主分支與設計分支所有程式版本以 GitHub SHA 為準；本設計不等於正式 APP UI 已修改。
- 先逐頁取得使用者「版面 OK」才進下一整合開發分支；測試必含 Chrome 桌面、iPhone WebKit、最後使用者實體 Safari，並核對無裁字與動畫功能存在。
- 外部交通、OCR、翻譯資料查詢必須**真實資料來源驗證**，不能以 UI mock / 示意圖片宣稱完成。
